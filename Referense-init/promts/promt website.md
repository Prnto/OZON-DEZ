Ти — провідний Fullstack-розробник та UI/UX архітектор сервісних веб-додатків. Твоє завдання — створити конверсійний, безпомилковий та естетично бездоганний веб-сайт для ліцензованої санітарно-епідеміологічної компанії дезінфекції, дезінсекції, озонування та пест-контролю (Pest Control HACCP).

### 1. ТЕХНОЛОГІЧНИЙ СТЕК:
- Фреймворк: SvelteKit (Svelte 5 з рунами $state, $derived, $props).
- Стилі: Vanilla CSS із суворою дизайн-системою (CSS-змінні токенів кольорів, радіусів, тіней, типографіки).
- Шрифти: Google Fonts ('Outfit' для заголовків, 'Plus Jakarta Sans' для основного тексту).
- Адаптер: @sveltejs/adapter-static для миттєвої віддачі статичних сторінок без серверних збоїв.

### 2. СТРУКТУРА ТА СТОРІНКИ:
1. Головна (Hub) — сильний Hero з оффером, швидкий вибір 5 напрямків, інтерактивний калькулятор, офіційні КВЕДи, блок відгуків та форма швидкого виклику.
2. /services — каталог послуг (дезінсекція комах, дератизація гризунів, дезінфекція вірусів/бактерій) з детальними тарифами.
3. /ozone — екологічне озонування газом O₃ (видалення запахів гару після пожежі, знищення плісняви, демеркуризація ртуті).
4. /b2b — пест-контроль за нормами HACCP для ресторанів, готелів, торгових мереж і складів із повним пакетом документів.
5. /agro — фумігація зерносховищ, елеваторів і силосів за КВЕД 01.61/01.62 з фітосанітарною сертифікацією.
6. /water — очищення та антимікробне знезараження систем водопостачання, резервуарів і свердловин за КВЕД 36.00.
7. /how-we-work — 5-кроковий регламент підготовки приміщення, гарантії безпеки препаратів 4-го класу малотоксичності.
8. /calculator — інтерактивний прозорий розрахунок без прихованих платежів.
9. /contacts — повні юридичні реквізити ТОВ, фактична адреса офісу, інтерактивна карта, прямі месенджери (Viber, Telegram).

### 3. ДИЗАЙН ТА UX-ВИМОГИ:
- Колірна палітра: Deep Navy (#040d1a, #081a36) як базова надійна основа, акцентний смарагдовий/бірюзовий (#00d4aa) як символ санітарної чистоти та безпеки.
- Чіткі фотографії без штучного розмиття чи мильних фільтрів: кожна сторінка має повнорозмірне чітке зображення у шапці, що відповідає саме її темі.
- Конверсійні елементи: плаваючий віджет швидкого дзвінка, прямі посилання у Viber/Telegram, модальне вікно замовлення консультації.

### 4. МОБІЛЬНА ОПТИМІЗАЦІЯ (ZERO UI BUGS):
- Всі поля input, select, textarea мають font-size: 16px для повного виключення примусового наближення (auto-zoom) в iOS Safari.
- Підтримка safe-area-inset-top та safe-area-inset-bottom для iPhone з Dynamic Island та сучасних Android з жестовою смужкою.
- Повний захист від горизонтального зміщення (overflow-x: clip, min-width: 320px).
- Клік-зони всіх кнопок та посилань не менше 44px × 44px для зручного натискання пальцем на смартфонах.
