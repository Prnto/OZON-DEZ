## 2. Ключові напрямки послуг
1. **Дезінсекція (`disinsection`):** Знищення тарганів, бліх, кліщів, клопів та комарів холодним або гарячим туманом із бар'єрним захистом.
2. **Дератизація (`deratization`):** Знищення щурів та мишей, захист периметрів, безпечні контейнери з ключем для харчових об'єктів.
3. **Дезінфекція (`disinfection`):** Знезараження поверхонь, приміщень, резервуарів питної води сертифікованими розчинами 4-го класу безпеки.
4. **Озонування O₃ (`ozonation`):** Глибока екологічна санація газом озоном. Знищення 99.9% вірусів, бактерій, спор цвілі та стійких запахів без хімічної плівки.
5. **Пест-контроль HACCP (`pest-control`):** Сертифікована програма санітарного аудиту для HoReCa, харчових виробництв, складів і супермаркетів із повним пакетом документів та журналами перевірок.

## 3. Технічний стек та архітектура
* **Фреймворк:** SvelteKit 2 + Svelte 5 (виключно Runes: `$state`, `$derived`, `$props`, `$effect`).
* **Мова:** TypeScript з суворою типізацією.
* **Стилізація:** Pure Vanilla CSS (без Tailwind / Bootstrap). Глобальна дизайн-система токенів у `src/app.css`.
* **Іконки:** Бібліотека `phosphor-svelte` (усі піктограми виключно в SVG-форматі, жодних сирих емодзі в інтерфейсі).
* **Локалізація (i18n):** Реактивний стан `langState.current` (`ua` | `ru` | `en`) у `src/lib/state/language.svelte.ts`. Тексти централізовані в `src/lib/data/content.ts`.
* **Модальні вікна:** Синглтон-стан `orderModal` у `src/lib/state/modal.svelte.ts`.
* **Інтеграція лідів:** `sendTelegramLead` у `src/lib/services/telegram.ts` надсилає дані у Telegram Bot через Cloudflare Worker або прямий API.
* **Білд та хостинг:** `@sveltejs/adapter-static` для деплою на GitHub Pages (`https://prnto.github.io/OZON-DEZ/`).

## 6. Правила розробки для агентів та розробників
1. **Жодних сторонніх CSS-фреймворків без узгодження:** верстка виключно на CSS-змінних із `src/app.css`.
2. **Усі іконки — через Phosphor Svelte:** `<IconName size={...} weight="..." />`. Жодних смайликів чи сирих символів емодзі в розмітці сайту.
3. **Обов'язкова валідація:** після будь-яких змін обов'язково запускати:
   ```bash
   npm run check
   ```
   (перевіряє гейт архітектури `check-structure.js` + `svelte-check` на 0 помилок).
